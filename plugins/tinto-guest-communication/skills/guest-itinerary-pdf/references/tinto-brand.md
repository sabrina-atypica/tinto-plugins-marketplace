# Tinto Travels Document Brand Reference

Shared with the Logistics plugin's `bus-company-itineraries` skill — kept in sync if either changes. Established for the Pre/Post-Tour Planning Guide redesign (2026-08-24) and carried forward as Tinto's standard for branded PDF output.

**For `guest-itinerary-pdf` specifically: this is the fallback/base system, not the default.** That skill's documents are sold under a client's own brand (Fox Run Vineyards, Boordy, etc.) and should use the tour's linked Client logo/accent color first — see the "Branding" section in `guest-itinerary-pdf`'s SKILL.md. Use this Tinto palette/typeface system as the base layout and typography, and as the fallback when a tour has no usable client branding on file.

## Palette

| Role | Name | Hex |
|---|---|---|
| Primary / headers | Burgundy | `#4A1528` |
| Accent | Gold | `#C9A84C` |
| Background | Cream | `#FAF7F2` |
| Secondary text | Slate | `#2C3E3A` |

## Typefaces

- Display / headers: **Cormorant Garamond** (italic for section flourishes)
- Body: **Inter**

## Layout conventions

- Clean header block with the Tinto Travels logo (burgundy/gold, transparent background).
- Section headers in Cormorant Garamond, burgundy.
- Body copy in Inter, slate, on a cream background.
- Guest-facing documents (like this itinerary) get the fuller treatment: the hand-authored line-icon set used per section in the Pre/Post-Tour Planning Guide, decorative dividers, and a proper closing/contact page — match that guide's look and feel rather than inventing a new style.

## If Tinto's brand assets have moved

This reference captures the values as of 2026-09-14. If a real Tinto logo file, icon set, or updated brand guidance is available in the session (e.g. shared via the desktop bridge or attached to the conversation), prefer that over reconstructing it from this text description — check before assuming this is the only source.
