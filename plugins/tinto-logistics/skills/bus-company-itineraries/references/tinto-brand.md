# Tinto Travels Document Brand Reference

Shared with the Guest Communication plugin's `client-itinerary-pdf` skill — kept in sync if either changes. Established for the Pre/Post-Tour Planning Guide redesign (2026-08-24) and carried forward as Tinto's standard for branded PDF output.

## Palette

| Role | Name | Hex |
|---|---|---|
| Primary / headers | Burgundy | `#4A1528` |
| Accent | Gold | `#C9A84C` |
| Background | Cream | `#FAF7F2` |
| Secondary text | Slate | `#2C3E3A` |

## Typefaces

- Display / headers: **Cormorant Garamond** (italic for section flourishes)
- Body: **Inter**

## Layout conventions

- Clean header block with the Tinto Travels logo (burgundy/gold, transparent background).
- Section headers in Cormorant Garamond, burgundy.
- Body copy in Inter, slate, on a cream background.
- For operational (non-guest-facing) documents like a transport schedule, keep the styling restrained — correct fonts, header/footer, and palette are enough. Save the fuller icon/section treatment (line icons, decorative dividers) for guest-facing pieces.

## If Tinto's brand assets have moved

This reference captures the values as of 2026-09-14.
